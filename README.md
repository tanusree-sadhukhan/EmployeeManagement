\# Employee Management Portal



A web-based Employee Management Portal.



\## Features

\- Employee Registration

\- Employee Search



\## Technologies

\- Python

\- Flask

\- HTML

\- Git and GitHub

\## Installation Guide



1\. Install Python.

2\. Clone the repository.

3\. Install dependencies:

&#x20;  pip install -r requirements.txt

4\. Run the application:

&#x20;  python app.py
